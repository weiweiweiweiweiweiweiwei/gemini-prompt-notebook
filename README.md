# 常用提示詞

把常用的 AI 指令存起來，點一下就填進輸入框（或複製）。
一共有 **兩個版本**，資料格式相同，可以互相搬運：

| 版本 | 位置 | 適合 |
|---|---|---|
| **Chrome 外掛** | 專案根目錄 | 自己的電腦，能安裝擴充功能 |
| **網頁版** | `web/` | 公司／公家機關的電腦，不能裝外掛，開網址就能用 |

兩邊的外觀刻意做得不一樣，一眼就分得出現在用的是哪一個：
外掛是半透明的毛玻璃筆記本，網頁版是實心高對比的卡片。

---

## 一、Chrome 外掛

### 安裝（第一次才要做）

1. 打開 Chrome，網址列輸入 `chrome://extensions` 後按 Enter
2. 把右上角的 **「開發人員模式」** 打開
3. 點左上角 **「載入未封裝項目」**
4. 選擇這個資料夾（有 `manifest.json` 的那一層）
5. 回到下面任一網站並 **重新整理**（按 F5）

支援三個網站，提示詞三邊共用：

| 網站 | 按鈕位置 |
|---|---|
| <https://gemini.google.com> | 輸入框「＋」旁邊 |
| <https://chatgpt.com> | 輸入框「＋」旁邊 |
| <https://claude.ai> | 輸入框迴紋針旁邊 |

按鈕會自動套用各站原生樣式（大小、圓角、顏色都一致），看起來像內建功能。

> 點 Chrome 右上角的擴充功能圖示會開啟 **快速複製小視窗**，
> 在任何網站（包含側邊欄的「問問 Gemini」）都能複製提示詞後貼上。

> 電腦重開機、Chrome 關掉再開，外掛都會自動在，不用重裝。

### 怎麼用

| 想做的事 | 怎麼操作 |
|---|---|
| 打開面板 | 點輸入框工具列的 **書籤圖示** |
| 關閉面板 | 點面板 **外面** 的地方（或按 Esc） |
| 換書籤 | 點上面的書籤標籤 |
| 使用提示詞 | 點卡片中間的 **標題** → 填進輸入框 + 複製，卡片顯示 **Copied**（面板不會關） |
| 調整順序 | 按住卡片最左邊的 **⣿** 上下拖曳 |
| 書籤換位置 | **長按** 書籤約半秒，再左右拖曳（故意設計成不好觸發，避免點選時誤拖） |
| 修改內容 | 點卡片右邊的 **鉛筆** 圖示 |
| 新增提示詞 | 點面板最下面的 **＋ 新增提示詞** |
| 刪除提示詞 | 進入編輯畫面 → 左下角 **刪除** → 再按一次確認 |
| 新增書籤 | 點書籤列最右邊的 **＋**（可取名 + 選 6 種顏色，最多 8 個） |
| 改名／改色／刪書籤 | 點書籤下方那排文字右邊的 **齒輪** |
| 備份／搬到別台 | 點面板右下角的 **備份／同步** |

填入之後 **不會自動送出**，也 **不會關閉面板**；
可以連續點好幾個提示詞，看完內容再自己按 Enter。

## 二、網頁版

### 怎麼開

`web/` 資料夾就是完整的網頁，沒有後端、沒有帳號、不用連任何伺服器。
三種方式擇一：

**A. 直接開檔案（最單純，公家機關電腦推薦）**
把整個 `web` 資料夾複製到隨身碟或桌面，double-click `index.html` 就能用。
不需要網路、不會被公司的網頁過濾擋掉。

> 少數電腦會擋掉「本機檔案的儲存空間」。真的被擋到時，網頁最上方會出現紅色警告，
> 這時請改用下面的 B 或 C。

**B. 放到免費靜態空間**
把 `web` 資料夾整個拖進 [Netlify Drop](https://app.netlify.com/drop) 或
Cloudflare Pages，就會得到一個網址，之後輸入網址即可使用。

**C. GitHub Pages**
這個 repo 目前是 **Private**，GitHub Pages 需要 repo 是 Public（或付費方案）。
若要走這條路，得先把 repo 改成 Public，或另開一個只放 `web/` 的公開 repo。

### 網頁版和外掛的差別

| | 外掛 | 網頁版 |
|---|---|---|
| 點提示詞 | **直接填進** AI 的輸入框 | **只能複製**，再自己貼上 |
| 搜尋 | 無 | **有**（標題和內容都會找） |
| 資料存在哪 | Chrome 帳號 | 這台電腦的這個瀏覽器 |
| 外觀 | 毛玻璃筆記本 | 實心卡片 + 左側色條 |

> 網頁版為什麼不能自動填？
> 瀏覽器不允許一個網頁去操作另一個網站的內容（同源政策），這是安全機制，
> 沒有任何繞過方法。所以網頁版一律是「點一下複製，再自己貼上」。

### 鍵盤快速鍵

| 按鍵 | 功能 |
|---|---|
| `/` | 跳到搜尋框 |
| `Ctrl` + `N` | 新增提示詞 |
| `Esc` | 關閉對話框 |

## 三、兩邊怎麼同步

沒有雲端、不用註冊，靠 **手動匯出／匯入**。
兩邊都在同一個地方：外掛按 **備份／同步**，網頁版按右上角 **⇄**。

### 把家裡的提示詞帶到公司

1. 家裡的 Chrome：打開面板 → **備份／同步** → **複製代碼**
2. 把那串代碼用任何方式帶到公司（貼在 Email 給自己、記事本、隨身碟都行）
3. 公司的網頁版：按 **⇄** → 貼進「②把資料帶回來」→ 按 **匯入**

> 代碼很長是正常的，一定要 **從頭到尾整段** 複製，少一個字就讀不出來。
> 嫌麻煩的話改按 **下載備份檔**，得到一個 `.json` 檔，到另一邊選檔案就好。

### 合併 vs 完全取代

| 選項 | 做什麼 | 什麼時候用 |
|---|---|---|
| **合併**（預設） | 保留現有的，只把沒有的加進來 | 平常都用這個 |
| **完全取代** | 現有的整個刪掉，換成備份裡的 | 想讓兩台一模一樣時 |

兩種都要 **按兩次** 才會真的執行，按下去前會先告訴你會發生什麼事。

## 四、貼心設計（給長輩用的考量）

- 提示詞標題 **19～20px** 大字，按鈕高度 46～56px，好按不易點錯
- 刪除、匯入這種「會弄不見東西」的動作，一律 **按兩次** 才執行
- 編輯視窗 **不會** 因為點到旁邊就關掉，打到一半的字不會不見
- 匯入預設是「合併」，不會有一按就把舊資料洗掉的狀況
- 深色／淺色自動跟著系統（網頁版也可以手動指定）

## 五、檔案結構

```
manifest.json          外掛設定
src/
  store.js             資料格式 + chrome.storage 存取
  share.js             匯出／匯入（和 web/share.js 完全相同）
  content.js           注入按鈕、面板、所有互動
  styles.css           外掛的全部樣式（毛玻璃）
  popup.html / .js     工具列小視窗
web/
  index.html           網頁版
  store.js             同樣的資料格式 + localStorage 存取
  share.js             同一份匯出／匯入
  app.js               網頁版的互動
  styles.css           網頁版的樣式（實心高對比）
tools/
  checksync.py         檢查 src/ 和 web/ 的共用程式碼有沒有分岔
```

**重要：** `share.js` 和 `store.js` 裡標了「共用資料契約」的那一段，
兩邊必須一字不差，否則匯出匯入就會壞掉。改完跑一下：

```
python tools/checksync.py          # 檢查
python tools/checksync.py --fix    # 用 src/ 的內容覆蓋 web/
```

## 六、想改外觀的話

| 想改什麼 | 改哪裡 |
|---|---|
| 外掛的顏色、字級 | `src/styles.css` 最上面的 `:host` / `:host([data-theme="dark"])` 色票 |
| 外掛的視窗尺寸 | `src/styles.css` 的 `.gpn-book` |
| 網頁版的顏色、字級 | `web/styles.css` 最上面的 `:root` / `:root[data-theme="dark"]` |
| 網頁版幾欄 | `web/styles.css` 的 `.grid`（改 `minmax(min(340px, 100%), 1fr)` 的 340） |
| 書籤顏色 | 兩邊各自的 `--amber / --green / --blue / --rose / --purple / --teal` |
| 按鈕圖示 | `src/content.js` 的 `ICON_BOOKMARK` 等常數 |
| **AI 網站改版後按鈕不見了** | `src/content.js` 最上面的 `SITES` 陣列，各站的選擇器都集中在那裡 |

改完之後回到 `chrome://extensions`，按這個外掛的 **重新整理 ⟳**，再重整網頁。

## 七、疑難排解

**按鈕沒出現？**
先重新整理網頁。還是沒有的話，到 `chrome://extensions` 確認外掛是開啟狀態，再按 ⟳ 重新載入。
若輸入框旁真的插不進去，右下角會自動出現一顆 **圓形浮動按鈕** 當備援。

**點了標題但輸入框沒字？**
內容仍然已經複製到剪貼簿，直接在輸入框按 `Ctrl + V` 貼上即可。

**網頁版重開之後資料不見了？**
網頁版的資料存在「這個瀏覽器」裡。清除瀏覽資料、換瀏覽器、換電腦、用無痕視窗，
都會看不到。請定期用 **⇄ → 下載備份檔** 存一份起來。

**代碼貼上去說「看不懂這段內容」？**
多半是沒複製完整。改用「下載備份檔 → 選檔案」最不會出錯。

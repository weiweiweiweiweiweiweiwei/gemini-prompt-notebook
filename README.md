# 罐頭P

（原名「常用提示詞」、「特務P」）

把常用的 AI 指令存起來，點一下就填進輸入框（或複製）。
提示詞用 **書籤** 分類；提示詞很多的書籤，還可以在裡面再分 **資料夾**
（例如「ChatGPT」書籤 ＞「1. 寫作與改寫」資料夾 ＞「縮短文字」）。
資料夾是每個書籤自己決定要不要開的，像「常用」這種只放十來則的書籤，不開也沒關係。

只有 **網頁版**（`web/`）：開網址就能用，不用安裝任何東西。
（以前還有 Chrome 外掛，但公家機關的瀏覽器不能裝外掛、沒有人在用，4.37.0 起拿掉了，只留網頁版。）

---

## 一、怎麼用


畫面由上到下：書籤列（自己的書籤、＋，最右邊是自己開的符號、★ 我的最愛、時鐘 最近使用）→ 紙張（有資料夾的書籤左邊多一欄資料夾）→
最下面一排（由左到右）：**登入中的 Google 帳號頭像**、**＋ 新增提示詞**、**放大鏡（搜尋）**、齒輪（設定，也兼當雲端同步的狀態燈）。
「資源回收桶」在 **齒輪 → 左邊選單**，「全部提示詞」（網頁版，開在新分頁）在 **齒輪 → 其他**。

> **一定要登入才能用**（4.16.0 起）：沒登入時只會看到登入畫面，按 **用 Google 帳號登入** 才看得到提示詞。
> 齒輪左邊的圓形頭像是現在登入的帳號（有兩個帳號時一看就知道是哪個），點它可以看同步狀態、**登出**。
> 登出後畫面回到登入畫面，這台電腦上的提示詞會清掉；雲端上的都還在，再登入就回來。詳見第三節。

筆記本的 **左右兩邊邊緣** 可以拖曳調整寬度（滑鼠移過去會出現一條細線），**按兩下** 恢復預設寬度。
寬度記在這台電腦，下次打開還是一樣。網頁版和工具列小視窗還可以在 **齒輪 → 背景** 換成自己的桌布。

網頁版整個畫面預設放大成 **140%**（不用再自己按 Ctrl＋放大）。想調整的話，改 `web/app.js` 的 `GPN_WEB_ZOOM`
和 `web/all.css` 的 `--zoom`。之前有用瀏覽器放大過的話，請在網頁版按一次 **Ctrl＋0** 恢復 100%，不然會放大兩次。

| 想做的事 | 怎麼操作 |
|---|---|
| 上一步、下一步 | 滑鼠側邊的「上一頁」「下一頁」鍵（或 Alt＋←、Alt＋→）：在罐頭P 裡往回、往前（換過的書籤、資料夾，設定裡的每一頁），不會跳離網頁（4.37.0） |
| 換書籤 | 點上面的書籤標籤（有資料夾的書籤，一律先顯示 **第一個資料夾**） |
| 找剛剛用過的 | 書籤列最右邊的 **時鐘** 圖示「最近使用」（見下面） |
| 收藏最常用的 | 點卡片右邊的 **☆**，收進書籤列右邊的 **★ 我的最愛**；連續點可以換成 **？、i** 之類的其他符號（見下面「星號」） |
| 使用提示詞 | 點卡片中間的 **標題** → 複製，卡片顯示 **Copied**，到 AI 網站的輸入框按 Ctrl＋V 貼上 |
| 拿到 Gemini／ChatGPT 用 | 點卡片最右邊的 **⋮** → 左上的 **Gemini**／右上的 **ChatGPT** 標誌（見下面「⋮ 選單」） |
| 調整順序 | 按住卡片最左邊的 **⣿** 上下拖曳 |
| 搬到別的資料夾、書籤 | 按住 **⣿** 拖到左邊的資料夾（或上面別的書籤）上，那一格亮起來時放開，就搬過去了（放在最後面）。搬過去之後畫面會跟著換到那裡、捲到那一則，外圍亮一圈白光 1.8 秒再慢慢暗掉（4.33.0；⋮ → 拷貝出來的那則也會亮）。拖出去時滑鼠旁邊會跟著半透明的卡片，對準資料夾、書籤時多一行「→ 移動至 ○○」，和電腦拖檔案一樣 |
| 拖到別的書籤（4.31.0） | 拖著提示詞 **停在別的書籤上不動**：書籤底下的線慢慢填滿，**1.5 秒** 後就切到那個書籤，提示詞還拿在手上，可以接著拖到那裡的資料夾，或直接放在清單上（放進正在看的資料夾、放開的位置）。直接放在書籤上照舊是馬上搬過去，不用等 |
| 搜尋 | 點底下的 **放大鏡**，打任何字：標題或內容有出現的都會列出來，不分書籤、全部在同一頁，關鍵字會標黃色。空白隔開的幾個字要都有出現才算。點一下照樣是使用；按 Esc、右邊的 ×、或點任何書籤就離開 |
| 書籤換位置 | **長按** 書籤約 0.25 秒，再左右拖曳（一般點一下不會誤拖） |
| 修改內容 | 點卡片右邊的 **鉛筆** 圖示（「實際的 Prompt 內容」下面會顯示字數） |
| 新增提示詞 | 點面板最下面的 **＋ 新增提示詞**（會放進目前的書籤／資料夾的 **最上面**，4.35.0 起；那一則會亮一下） |
| 回到上次用的地方 | 打開時會自動切到 **最後一次點（複製）的那則** 所在的書籤、資料夾，捲到它那裡（4.35.0）。最近使用跟著帳號同步，所以換一台電腦打開，也會接著上一台的位置。打開之後自己點了任何地方就不會再自動跳 |
| 刪除提示詞 | 卡片最右邊的 **⋮** → 最下面紅色的 **垃圾桶**（編輯畫面左下角的 **刪除** 也可以）。不會直接不見，會先放進 **資源回收桶**（見下面） |
| 分享給建立分身的人、分身 | 卡片最右邊的 **⋮** → 右下的 **分享** 箭頭，勾選要給誰（見下面「分享」） |
| 新增書籤 | 點自己的書籤後面的 **＋**（取名不限字數，太長的在書籤上用「…」、滑鼠移上去看全名；點顏色按鈕可以換 24 種顏色（4.39.0 起），最多 8 個；一開始不分資料夾） |
| 一頁看完全部提示詞 | 網頁版：**齒輪 → 其他 → 全部提示詞**：所有內容顯示在同一頁，讓「問問 Gemini」看得到全部提示詞（見下面「全部提示詞：給問問 Gemini 看」） |
| **設定** | 點「新增提示詞」右邊的 **齒輪**，見下面「設定裡有什麼」 |

### 我的最愛、最近使用

書籤列最右邊固定有兩個窄窄的書籤（不能刪除、不能改名、不能拖），只有圖示：
左邊的 **★** 是 **我的最愛**、最右邊的 **時鐘** 是 **最近使用**，滑鼠移上去看得到名稱。

**我的最愛**：把最常用的幾則集中在一起，不用到各個書籤裡找。

- 點任何一則提示詞右邊的 **☆**，變成金色 **★** 就收進來了；再按一次就拿掉（提示詞本身還在原本的書籤）。
- 標題下面有「從哪個書籤來的」；在這裡按鉛筆，改的就是原本那一則。
- 按住左邊的 **⣿** 可以排自己的順序，不會影響它在原本書籤裡的位置。
- 原本那則被刪掉的話，這裡也會跟著消失。
- 連結 Google 雲端硬碟的話會跟著同步；下載的備份檔裡也有，換電腦匯入後一樣在。

**最近使用**像 YouTube 的觀看記錄：

- 點過的提示詞會自動記下來，**最新的在最上面**，依日期分成「今天」「昨天」「星期三（9/17）」「9月10日」。
- 最多 **50 則**，超過就把最舊的拿掉；同一則用了好幾次只會出現一次（在最新那次的位置）。
- **在「最近使用」裡面點，順序不會變**（Copied 就出現在點的那一則上）；在其他書籤點了，才會排到最上面。
- 每一則左邊是使用時間、標題下面有「從哪個書籤來的」；原本那則被改過的話，顯示改過後的樣子。
- 右邊的 **×** 可以把單一則從記錄移除；最下面有 **清除全部使用記錄**（按兩次）。
  清除記錄不會動到提示詞本身。
- 連結 Google 雲端硬碟的話，記錄也會跟著同步（別台電腦用過的，這台的「最近使用」也看得到）。
  下載的備份檔裡也有記錄，換電腦匯入後一樣在（要分享提示詞給別人時，對方匯入也會看到你的記錄）。

### 星號：像 Gmail 一樣換不同的符號

平常卡片右邊的 **☆** 按一下就收進「我的最愛」、再按一下就拿掉。
到 **齒輪 → 星號** 多開幾種符號（和 Gmail 的「星號」設定一樣：六種顏色的星星，還有 **紅色驚嘆號、橘色雙箭頭、黃色驚嘆號、綠色勾勾、藍色資訊、紫色問號**），
之後 **連續點** 同一顆星號，會照「使用中」的順序換下去，換完一輪就取消：

> ☆ → ★ 我的最愛 → **？** 紫色問號 → **i** 藍色資訊 → ☆（沒有標記）

- **每開一種符號，書籤列就多一個書籤**，在 ★ 我的最愛的左邊，只有圖示（滑鼠移上去看得到名稱）。標了那個符號的提示詞都收在裡面，用法和我的最愛一樣（可以拖曳排順序、按鉛筆改的就是原本那則）。
- 設定裡上面一排是 **使用中**、下面一排是 **沒使用**，**點一下就移到另一排**（Gmail 是用拖的，這裡改成點的，比較好按）。
- **換順序**：在「使用中」那排、或書籤列上的符號書籤 **長按再左右拖曳**（和一般書籤一樣）。
  這個順序就是連續點星號時換的順序，兩邊會一起變。黃色星星（我的最愛）固定排第一個。
- 黃色星星就是「我的最愛」，固定排第一個、不能移走。黃色星星以外最多再開 **6 種**（書籤列才放得下）。
- **預先設定** 和 Gmail 一樣有「1 顆星」（只有我的最愛）、「4 顆星」（黃色星星、藍色星星、綠色勾勾、紅色驚嘆號）。
- 把某種符號移到「沒使用」，標了它的提示詞不會忘記，只是那個書籤先收起來；加回來就又出現了。
- 一則提示詞同時只會有一種符號。符號和我的最愛一樣會跟著 Google 雲端硬碟同步，也會放進下載的備份檔。
- **在我的最愛、符號書籤按齒輪**（4.26.0 起）會打開「這個符號」那一頁，可以：
  - **建立成新書籤**：把標了這個符號的提示詞複製一份，變成一個一般的書籤（取名字、挑顏色；複製的不帶符號，原本的和符號書籤都不動）。
  - **清除全部標記**：一次拿掉全部的這個符號，提示詞留著。
  - **刪除這些提示詞**：一次全部移到資源回收桶（可以還原，會連符號一起還原）。
  - **從書籤列拿掉**這個符號書籤（我的最愛不能拿掉）。後面三個都要按兩次。

### ⋮ 選單：用 Gemini、ChatGPT 開啟、拷貝、分享，或刪除

每張卡片最右邊的 **⋮**（在鉛筆右邊）。4.28.0 起是四格加最下面一條，只有圖示（滑鼠移上去看名稱）：

| 位置 | 做什麼 |
|---|---|
| 左上 **Gemini 標誌** | 開一個新分頁到 Gemini，提示詞已經複製好，在輸入框按 Ctrl＋V 貼上 |
| 右上 **ChatGPT 標誌** | 同上，開的是 ChatGPT |
| 左下 **拷貝** | 在這一則正下方多一則一模一樣的，標題後面加「 (複製)」，內容不變（新的那則不帶星號） |
| 右下 **分享** | 分享給建立分身的人、其他分身（見下面「分享」） |
| 最下面紅色 **垃圾桶** | 放進資源回收桶（不用進編輯畫面；要找回來到 設定 → 資源回收桶 還原） |

用方向鍵也可以在四格之間移動。

用 AI 開啟也算「用過」，會記進「最近使用」。

**有開資料夾的書籤**，左邊會多一欄資料夾：

| 想做的事 | 怎麼操作 |
|---|---|
| 換資料夾 | 點左邊資料夾欄的名稱 |
| 資料夾換位置 | **長按** 資料夾約 0.25 秒，再上下拖曳（和書籤同一套，一次可以拖好幾格） |
| 新增資料夾 | 資料夾欄最下面的 **＋ 新增資料夾**（每個書籤最多 12 個） |
| 資料夾改名／刪除 | 資料夾右邊平常顯示 **有幾則**；滑鼠移到那一格，數字會變成 **鉛筆**，點它 |

### 資源回收桶

刪掉的提示詞（連同刪掉的書籤、資料夾裡的提示詞）不會直接不見，先放進 **資源回收桶**，像電腦的資源回收桶一樣。
從 **齒輪 → 左邊選單最下面的「資源回收桶」** 進去；回收桶是一個獨立的空間：上面的書籤、底下的頭像、搜尋、設定都收起來，
背景照舊（自己選的那張），只是四周會依序彈出 4 個大大小小、有前後景模糊的紅色警示三角形（提醒這裡是危險區域）。
最上面一條左邊是 **← 回到設定**（按 Esc 也可以）、右邊是 **清空**（按兩次）。

- 裡面的提示詞 **不能用、不能拖、不能加星號、不能編輯**：點一下是 **選取**（藍色框），不會複製。
- 選很多則：按住 **Shift** 點，選一整段（點第一則、Shift 點最後一則＝全部）；按住 **Ctrl**（Mac 是 ⌘）點，跳著選；**Ctrl＋A** 全選；**Esc** 取消選取。
- 選好之後用底下的 **還原（N）** 放回原本的書籤、資料夾，星號也會標回去。原本的書籤、資料夾被刪掉了的話（4.40.0 起），會照刪掉時的樣子（名稱、顏色、備註、資料夾）一起放回來，而且回到原本的位置（4.41.0）；回收桶裡那一則會標「已刪除，還原時會放回來」。書籤已經 8 個放不下時，才放進第一個書籤；
  或 **永久刪除（N）**（按兩次，鍵盤的 **Delete** 也可以）。沒選任何一則時，這兩顆按不下去。
- 每一則右邊的 **⋮** 也可以單獨 **還原**、**永久刪除**。
- 回收桶跟著帳號同步，也在下載的備份檔裡。

### 全部提示詞：給「問問 Gemini」看（網頁版）

筆記本平常一次只顯示一個書籤，卡片上也只有前幾個字。網頁版 **齒輪 → 左邊選單最下面的「全部提示詞」**，
按了會換到另一頁（`all.html`）：**所有書籤、所有資料夾的提示詞，完整內容用純文字列在同一頁**，像一份記事本。

- 依「書籤 → 資料夾 → 提示詞」分段，每一則前面有編號（#1、#2…），★ 是我的最愛。
- 沒有卡片、按鈕、收合，所有字都直接攤在頁面上；十幾萬字也沒問題（實測約 15 萬字，重畫一次 0.03 秒）。
- 上面一條可以只看某一個書籤，或按 **全部** 看所有書籤。編號永遠照「全部」的順序，只看一個書籤時也不會變。
- 有連結 Google 雲端硬碟的話，打開這一頁時會先同步一次；網頁版在另一個分頁改了，這一頁也會跟著更新。
- 右上角的 **⬇ 另存新檔** 把全部提示詞存成一個記事本檔 **`罐頭P_全部提示詞_20260929.txt`**（日期是存檔當天），
  內容和這一頁一樣（書籤 → 資料夾 → 編號、標題、完整內容）。不管上面選了哪個書籤，一律存全部。
- 標題後面的 **★** 是我的最愛，**〔紫色問號〕** 這種是標的其他符號。
- 按左上角 **← 回到筆記本** 回去。這一頁可以直接加入書籤：
  `https://weiweiweiweiweiweiweiwei.github.io/gemini-prompt-notebook/all.html`

搭配 Chrome 的「問問 Gemini」這樣用：

1. 一個分頁開公文，另一個分頁開這一頁。
2. 把兩個分頁都分享給「問問 Gemini」，描述情境，請它挑該用哪一則（它可以用編號回答）。
3. 回到這一頁，選取那一則的內容複製；或回到筆記本點那一則。


### 分身：不用 Google 帳號，也能把提示詞分給同事（4.24.0）

想把某個書籤裡的幾個資料夾、幾則提示詞給同事用，但同事不想（或不能）用 Google 帳號登入時，就建立一個 **分身**。

1. **齒輪 → 分身 → ＋ 建立分身**：分兩步（4.30.0 起）。
   - **第 1 步**：取個名字（例如「業務組」）、挑一個頭像（點按鈕才展開），按 **繼續**。
   - **第 2 步：選擇提示詞**，整個視窗都是樹狀圖：勾選要給的書籤、資料夾、提示詞（勾書籤＝裡面全部、勾資料夾＝裡面全部，也可以只勾幾則）。
     書籤、資料夾一開始都是收起來的，點左邊的三角形展開；只有核取方塊勾得到，點文字不會勾到。
     「上一步」「建立分身」固定在視窗最下面。
2. 按 **建立分身**，會拿到一組 16 碼的 **分身代號**（例如 `K7QM-3XPA-9RVD-H2WN`）。按 **複製代號和網址** 貼給同事。
3. 同事打開網頁版，在登入畫面按最下面的小字 **選擇其他登入方式**，輸入代號就能用：
   新增、修改、刪除都可以，就跟一般帳號一樣；換一台電腦用同一組代號登入，看到的也一樣。

- **資料存在哪裡**：建立的人自己的 Google 雲端硬碟，一個分身一個檔案「罐頭P 分身 - 名稱.json」，
  同事新增、修改的也都存在那裡。同事沒有 Google 帳號、碰不到雲端硬碟，所以由中繼（`supabase/functions/gpn-clone`）代為讀寫那個檔案。
- **各自獨立**：分身是建立當下複製的一份，之後兩邊各改各的。想把自己後來改的送過去，按分身的 **推送資料**（以前叫「再推一次」）：
  分身裡已經有的會換成你現在的版本（分身裡被改過的會標「分身裡的不一樣」，不想蓋掉就取消勾選），沒有的就加進去；
  分身自己新增的不會動。
- **進入分身**：建立的人可以直接用那個分身的身分使用、編輯，改完到 齒輪 → 分身 按 **回到我的帳號**，不用重新登入 Google。
- **頭像**：分身沒有 Google 大頭貼，建立時挑一個（幾何風格的動物，或扁平插畫的人物）。
  建立的人點分身清單裡的頭像、用分身的人在 齒輪 → 分身，都可以再換。
- **分身卡片**（4.32.0）：下面兩顆文字鈕：**進入分身**、**推送資料**（推送資料就是以前的「再推一次」）；右上角 ⋮ 裡是 **拷貝**、**延長期限**、**換一組代號**、**停用**。
- **直接改名稱、頭像**（4.33.0）：不用進入分身。滑鼠移到分身名稱上會出現鉛筆，點了直接改（Enter 或點別的地方就存，Esc 取消）；
  滑鼠移到頭像上，右下角出現鉛筆，點了換頭像。
- **拷貝**（4.33.0）：⋮ → 拷貝，在原本那張的正下方多一個一模一樣的分身：提示詞一樣、名稱後面加「（副本）」、到期日一樣，
  頭像隨機換一個不同的，代號是新的。
- **換一組代號**（4.32.0；4.33.0 起在 ⋮ 裡）：⋮ → 換一組代號（按兩次）。分身要從 A 同事轉給 B 同事時用：舊代號馬上失效，用舊代號的裝置下次連線就被登出，分身裡的提示詞、名稱、頭像、到期日都不變，把新代號給 B 就好。
- **代號就像密碼**：拿到代號的人都能使用、修改那個分身。不想給了就按 **更多 → 停用**（按兩次）：
  代號馬上失效，用這個分身的裝置下次連線（打開、切回分頁、或做任何修改）時就被登出，那台電腦上留著的提示詞也一起清掉。
  但什麼都不刪：雲端上的都還在，建立的人照樣可以 **進入分身**。
- **停用了的分身**：卡片變成黯淡的灰色（虛線框、頭像去色、代號劃掉），排到清單最下面的「已停用」。
  **更多** 裡換成 **拷貝**、**重新啟用**、**換一組代號**（選一個新的到期日，同一組代號又能用）、**銷毀**（按兩次：代號不能再用，檔案丟進雲端硬碟的垃圾桶）。
  所以要銷毀，一定要先停用。
- **一年後自動停用**（4.25.0 起，不再自動刪除）：建立滿一年，和按了停用一樣。
  重新啟用之後，同事在登入畫面會看到代號已經填好，按登入就回來了。
- 分身頁標題右邊的 **i** 按一下，看分身的說明。
- 建立分身的人撤銷了罐頭P 的授權（或很久很久沒用、Google 讓登入失效），分身會同步不了，同事會看到提示；
  建立的人打開罐頭P 重新登入一次就好，同事那邊沒送出的修改不會不見。

### 分享：建立分身的人和分身之間互相傳提示詞（4.28.0）

有分身之後，**建立分身的人**（建立分身的人）和 **分身**、分身和分身之間，都可以把提示詞分享給對方。
例如建了 10 個分身給 10 位同事：成員 1 可以分享給成員 2、7、9；成員 9 可以分享給建立分身的人和成員 3。

1. **寄出**：卡片的 **⋮** → 右下的 **分享**，勾選要給誰（可以勾很多個，有「全部勾選」），按 **分享給 N 位**。
   分身看得到建立分身的人和其他分身；建立分身的人看得到自己建立的分身。停用（到期）的分身不會出現在名單裡。
2. **收到**：對方左下角的 **頭像會變成一封信**，右上角的紅色數字是收到幾則；筆記本開著的話還會跳一個提示。
   點信封，書籤列的 **最左邊** 會多一個 **信箱** 書籤（4.31.0 起），分享來的提示詞都放在裡面，新的在最上面：
   - 用起來和一般的提示詞一樣：點標題複製（Copied）、星號、鉛筆（看、改）、⋯（Gemini、ChatGPT、拷貝、分享、刪除）。
   - 每一則上面多一行 **寄的人**：分身用它的頭像和名稱；建立分身的人用他 Google 帳號的名稱和大頭貼。
   - 想留下來的，按住 ⣿ 拖到自己的書籤、資料夾（見下面「拖到別的書籤」），或用鉛筆的「放在哪裡」搬走。
   - 信箱 **空了**（都刪掉、搬走了）就自動消失；下次有人分享、點信封時才會再出現。信箱不算在 8 個書籤的上限裡；和其他書籤一樣可以長按左右拖曳換位置。

- **存在哪裡**：每一份分享是建立分身的人雲端硬碟裡的一個小檔案「罐頭P 分享.json」（一個收件人一個），
  收的人點信封、收進「信箱」書籤之後就自動刪掉。用分身代號登入的人一樣由中繼代為處理。
- 多久收到：對方的罐頭P 每次同步時看一下信箱（最多 30 秒看一次）；網頁版切回分頁時也會同步。
- 信箱打開時，最下面的 **帳號與同步** 可以到帳號頁（有信的時候點頭像會先打開信箱）。

## 三、怎麼同步

### 方法一：登入 Google 帳號，自動同步（一定要登入）

4.16.0 起沒登入就不能用：一打開就是登入畫面，按 **用 Google 帳號登入**：

1. 到 Google 的畫面 **選帳號**——公司帳號、個人帳號請選對，之後每台電腦都選同一個。
2. Google 會問能不能讓罐頭P 存取雲端硬碟，按 **允許**（有勾選框的話，要把雲端硬碟那一項打勾）。
3. 回到罐頭P 就開始同步。網頁會整頁換過去再回來。

（直接雙擊開檔案的網頁版不能登入——Google 沒辦法把人帶回電腦裡的檔案，請用網址打開。）

提示詞會存在你的 Google 雲端硬碟裡的 **「罐頭P 提示詞筆記本.json」** 這個檔案：

- 罐頭P 只申請「只能碰自己建立的檔案」這個最小權限，看不到雲端硬碟裡的其他東西。
- 檔案可以改名、搬到別的資料夾，罐頭P 都找得到；**請不要手動修改內容**。
- 被刪掉的話，下次同步會用這台電腦上的提示詞重建一個。
- 雲端同步頁有 **在 Google 雲端硬碟裡查看這個檔案** 的連結。

登入之後：

- 改了提示詞，**先存在這台電腦的瀏覽器**（馬上存好），大約一秒後再送上雲端硬碟；
  打開面板、回到網頁版的分頁時，會先把別台改的拉下來。只是切換書籤不算改東西，不會送。
- 還沒送上去就關掉網頁也沒關係：提示詞已經存在這台，下次打開會接著送（切到別的分頁時也會馬上送）。
- **齒輪** 兼當同步狀態燈：改了提示詞，齒輪會變成 **綠色雲朵**（雲朵不動、裡面的箭頭往上跑）→ 送完打個勾 → 變回齒輪。
  齒輪右上角出現 **黃點**＝沒連上網路（恢復後會自己補上）；**紅點**＝同步失敗。有點的時候按齒輪，會直接打開「雲端同步」看原因。
- **登入時一律以雲端為準**：雲端已經有筆記本，這台就換成雲端的樣子；雲端還沒有（第一次用），才把這台的傳上去。
  以前是「和雲端合併」，結果「中斷連結 → 在這台亂改 → 再登入」，改壞的會蓋進雲端，所以改成一定要登入、雲端才是正本。
  從沒登入過的舊電腦，原本的提示詞會另外留一份：**齒輪 → 備份** 有「下載登入前的提示詞」，不需要了可以刪掉。
- 同一個帳號只是登入過期、重新登入：這台還記得上次同步到哪，照平常的方式同步，還沒送出的修改不會不見。
- 兩邊都改過（例如一台沒網路時改了、兩台電腦都有改、關掉網頁時還沒送出）：
  拿「上次同步好的內容」當起點，比出兩邊各做了什麼再合在一起——**刪掉的不會再跑回來**，
  新增、修改、搬移、排序兩邊的都保留；同一則兩邊都改了，以正在用的這台為主。
  一邊刪、另一邊剛好改了它的內容，會留下改過的（寧可多、不會少）。
- 同步到一半又改了東西（例如快速連續刪除）：不會被同步到一半的舊內容蓋掉，同步完會馬上再送一次。
- **登出**（點右下角頭像 → 登出）：先把還沒送出的送上去，再清掉這台的提示詞，回到登入畫面。
  雲端硬碟上的都還在，再登入就回來。沒網路、還有修改送不上去時，會先警告，要再按一次才登出。
- 換另一個 Google 帳號登入，看到的是那個帳號自己的提示詞，不會把前一個帳號的帶過去。
- 頭像：登入時 Google 會給大頭貼；沒給的話（例如 4.16.0 以前就登入的），會改向雲端硬碟要這個帳號的大頭貼，不用重新登入。
  兩邊都拿不到才顯示 Email 第一個字。
- 不想用了：登出後，到雲端硬碟把「罐頭P 提示詞筆記本.json」「罐頭P 背景圖」刪掉。

> 資料存在哪、誰看得到、怎麼刪除，寫在 [隱私權政策](https://weiweiweiweiweiweiweiwei.github.io/gemini-prompt-notebook/privacy.html)。

### 方法二：手動匯出／匯入（不想用帳號、或要分享給別人時）

在 **齒輪 → 備份**。以前還有「複製代碼／貼上代碼」，現在統一只用 **備份檔**（`.json` 檔）。

備份檔裡有：所有書籤、資料夾、提示詞，**我的最愛、星號（各種符號和標了哪些）、最近使用記錄、背景**（4.15.0 起）。
換到新電腦匯入，這些都會跟著過去。4.15.0 以前下載的舊備份只有提示詞，「完全取代」時會留著新電腦原本的我的最愛和記錄。

檔名：有連結 Google 雲端硬碟時會帶帳號 @ 前面那段，例如 apple@gmail.com 下載的是 `罐頭P_apple_20261004.json`，
一看就知道是哪個帳號的；沒連結時是 `罐頭P-備份-20261004.json`。

### 把家裡的提示詞帶到公司

1. 家裡的 Chrome：打開面板 → **齒輪 → 備份** → **下載（做備份）**，得到一個 `罐頭P_帳號_日期.json`（沒連結雲端是 `罐頭P-備份-日期.json`）
2. 把這個檔案用任何方式帶到公司（寄 Email 給自己、隨身碟、雲端硬碟都行）
3. 公司的網頁版：**齒輪 → 備份** → **📁 選擇備份檔…** 選這個檔案 → **合併** → 按兩次 **匯入**

> 選好檔案後，匯入鈕上面會先寫出「會加入幾則」，確認沒問題再按。

### 合併 vs 完全取代

| 選項 | 做什麼 | 什麼時候用 |
|---|---|---|
| **合併**（預設） | 保留現有的，只把沒有的加進來 | 平常都用這個 |
| **完全取代** | 現有的整個刪掉，換成備份裡的 | 想讓兩台一模一樣時 |

兩種都要 **按兩次** 才會真的執行；選好檔案後，匯入鈕上面會先寫出會發生什麼事。

合併時每一層都是「先比 id、再比名稱」：同名的書籤、同名的資料夾會併在一起，
同一個清單裡標題＋內容完全相同的提示詞會跳過，所以同一份備份匯入兩次也不會重複。

兩邊「有沒有開資料夾」不一樣時，以不弄丟分類為原則：
備份裡的書籤有資料夾、這台同名的書籤沒有 → 這台的書籤會自動開啟資料夾，原本的提示詞放進「一般」。

> 舊版匯出的備份一樣可以匯入。既有的資料也會自動升級，不會不見。

### 雲端同步（Google 雲端硬碟）的設定（管理員做一次就好）


## 五、資料格式（v4）

書籤有兩種長相：沒開資料夾的直接放 `items`，有開資料夾的放 `folders`（兩者只會有一個）。

```jsonc
{
  "version": 4,
  "activeId": "t_fav",                     // 目前選的書籤
  "tabs": [
    { "id": "t_fav", "label": "常用", "color": "amber",          // 不分資料夾
      "items": [ { "id": "p1", "title": "翻譯成英文", "content": "…" } ] },

    { "id": "t_chatgpt", "label": "ChatGPT", "color": "teal",    // 有資料夾
      "folders": [
        { "id": "f_chatgpt_1", "label": "1. 寫作與改寫",
          "items": [ { "id": "p_chatgpt_001", "title": "縮短文字", "content": "/shorten 請把下面的文字…" } ] }
      ] }
  ]
}
```

- 有開資料夾的書籤至少有一個資料夾（最後一個不能刪，不想分就到設定關掉）。
- 「目前看哪個資料夾」刻意不存檔：點書籤一律從第一個資料夾開始。
- 另外還有 `"recent": [ { id, title, content, usedAt, tabId, folderId } ]`：最近使用記錄，
  `id` 指向原本那則提示詞。畫面上是最右邊的「最近使用」書籤（`activeId` 可以是 `"t_recent"`）。
- 以及 `"favs": [ "p1", … ]`：我的最愛，依使用者排的順序存提示詞的 `id`（找不到的會自動拿掉）。
  畫面上是「最近使用」左邊的「我的最愛」書籤（`activeId` 可以是 `"t_star"`；注意不是預設書籤「常用」的 `t_fav`）。
- `"markTypes": [ "purple-question", "blue-info" ]`：設定 → 星號裡「使用中」的符號（黃色星星以外，種類的名稱沿用 Gmail 的英文名）；
  `"marks": { "purple-question": [ "p3" ] }`：標了各種符號的提示詞，和 `favs` 一樣依使用者排的順序。一則只會有一種符號。
  符號書籤的 `activeId` 是 `"t_mark_"` 加上種類，例如 `"t_mark_purple-question"`。
- 書籤可以有 `"note": "…"`：備註說明（最多 300 字，沒寫就沒有這一欄）。
- `"uses": { "p1": 12 }`：每則提示詞用了幾次（設定 → 使用次數）。兩台都用過時，合併會把兩邊各自多用的加起來。
- 匯出檔多了 `"app": "gpn"` 和 `"exportedAt"`，其他和上面一樣。
- 舊格式的升級規則寫在 `web/store.js` 最上面。

## 八、疑難排解


**網頁版重開之後資料不見了？**
沒連結雲端硬碟時，網頁版的資料只存在「這個瀏覽器」裡。清除瀏覽資料、換瀏覽器、換電腦、用無痕視窗，
都會看不到。連結 Google 雲端硬碟就會存到雲端；不想連結的話，請定期到 **齒輪 → 備份** 按 **下載（做備份）**。

**右上角一直顯示「未連線」或「同步失敗」？**
提示詞還是有存在這台電腦，恢復網路後會自己補同步。一直不好的話，到 **齒輪 → 雲端同步** 看錯誤訊息，
或按「立即同步」再試一次。

**說「和 Google 雲端硬碟的連結已經失效」？**
到 Google 帳戶移除過罐頭P 的存取權、改過密碼、或很久沒用時會這樣。重新連結同一個帳號就好，提示詞不會不見。

**說「剛剛沒有勾選允許存取 Google 雲端硬碟」？**
Google 的同意畫面上，雲端硬碟那一項要打勾。再按一次連結，這次記得勾。

**說「你的機關帳號不允許這個應用程式存取雲端硬碟」？**
見上面「機關的 Google Workspace 帳號連不上？」。

**匯入時說「看不懂這個檔案」？**
請選「罐頭P」**齒輪 → 備份 → 下載（做備份）** 下載的那個 `.json` 檔（檔名是 `罐頭P_帳號_日期.json` 或 `罐頭P-備份-日期.json`）。

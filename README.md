# Gemini 常用提示詞筆記本

在 Google Gemini 的輸入框上方加一顆「✨ 常用提示詞」按鈕，
點一下就能叫出筆記本風格的面板，選好提示詞直接填進輸入框。

---

## 一、安裝步驟（第一次才要做）

1. 打開 Chrome，網址列輸入 `chrome://extensions` 後按 Enter
2. 把右上角的 **「開發人員模式」** 打開
3. 點左上角 **「載入未封裝項目」**
4. 選擇這個資料夾（`Promt快捷鍵`，就是有 `manifest.json` 的那一層）
5. 回到下面任一網站並 **重新整理**（按 F5）

支援三個網站，提示詞三邊共用：

| 網站 | 按鈕位置 |
|---|---|
| <https://gemini.google.com> | 輸入框「＋」旁邊 |
| <https://chatgpt.com> | 輸入框「＋」旁邊 |
| <https://claude.ai> | 輸入框迴紋針旁邊 |

按鈕會自動套用各站原生樣式（大小、圓角、顏色都一致），看起來像內建功能。

> 另外，點 Chrome 右上角的擴充功能圖示會開啟 **快速複製小視窗**，
> 在任何網站（包含側邊欄的「問問 Gemini」）都能複製提示詞後貼上。

> 之後電腦重開機、Chrome 關掉再開，外掛都會自動在，不用重裝。

---

## 二、怎麼用

| 想做的事 | 怎麼操作 |
|---|---|
| 打開面板 | 點輸入框工具列（「+」旁邊）的 **書籤圖示** |
| 關閉面板 | 點面板 **外面** 灰黑色的地方（或按 Esc） |
| 換書籤 | 點上面的書籤標籤 |
| 使用提示詞 | 點卡片中間的 **標題** → 填進輸入框 + 複製，卡片顯示 **Copied**（面板不會關） |
| 調整順序 | 按住卡片最左邊的 **⋮⋮** 上下拖曳 |
| 修改內容 | 點卡片右邊的 **鉛筆** 圖示 |
| 新增提示詞 | 點面板最下面的 **＋ 新增提示詞** |
| 刪除提示詞 | 進入編輯畫面 → 左下角 **刪除** → 再按一次確認 |
| **新增書籤** | 點書籤列最右邊的 **＋**（可取名字 + 選 6 種顏色，最多 8 個） |
| **改名／改色／刪書籤** | 點 **作用中書籤上的鉛筆**（刪除會連裡面的提示詞一起刪，需按兩次確認） |

填入之後 **不會自動送出**，也 **不會關閉面板**；
可以連續點好幾個提示詞，看完內容再自己按 Enter，最後點旁邊空白處關閉。

---

## 三、貼心設計

- 提示詞標題 **20px** 大字，按鈕高度都在 46～56px，好按不易點錯
- 刪除要按 **兩次** 才會真的刪掉，避免誤觸
- 編輯視窗 **不會** 因為點到旁邊就關掉，打到一半的字不會不見
- 資料存在 `chrome.storage.local`，關電腦也不會消失
- 多個 Gemini 分頁會自動同步

## 四、想改外觀的話

| 想改什麼 | 改哪裡 |
|---|---|
| 顏色、字級、大小 | `src/styles.css`（最上面有深色／淺色兩組色票） |
| 視窗固定尺寸 | `src/styles.css` 的 `.gpn-book` 的 `width` / `height` |
| 書籤名稱（常用 / 其他） | `src/store.js` 的 `GPN_TAB_LABELS` |
| 按鈕圖示、行為 | `src/content.js`（`ICON_BOOKMARK`） |
| **Gemini 改版後按鈕不見了** | `src/content.js` 最上面的 `SEL`，選擇器全集中在那裡 |

改完之後回到 `chrome://extensions`，按這個外掛的 **重新整理 ⟳** 圖示，
再重整 Gemini 頁面即可。

### 書籤顏色

內建 6 色：`amber` 牛皮黃、`green` 森林綠、`blue` 天空藍、
`rose` 玫瑰粉、`purple` 薰衣草、`teal` 湖水綠。
每個顏色都有深／淺兩套色票，定義在 `src/styles.css` 最上方的
`--c-<顏色>-tab / dim / ink / paper / edge`，要調色改那裡就好。

## 五、疑難排解

**按鈕沒出現？**
先重新整理 Gemini 頁面。還是沒有的話，到 `chrome://extensions`
確認外掛是開啟狀態，再按 ⟳ 重新載入。

**點了標題但輸入框沒字？**
內容仍然已經複製到剪貼簿，可以直接在輸入框按 `Ctrl + V` 貼上。
（Google 偶爾會改版輸入框結構，若持續發生請回報。）
